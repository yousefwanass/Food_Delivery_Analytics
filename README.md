# 🍔 Food Delivery Analytics

An End-to-End Data Analytics project that analyzes food delivery operations using SQL Server, Python, Excel, and Power BI.

---

## 📌 Project Overview

This project demonstrates the complete data analytics workflow, from database design to interactive dashboards.

The project includes:

- Database Design
- Data Generation
- SQL Business Queries
- Python Data Analysis
- Excel Reporting
- Power BI Dashboards

## 🚀 How to Run

### SQL

Run the SQL scripts in the following order:

1. Create_Tables.sql
2. Insert_Data.sql
3. Business_Queries.sql

### Python

Install the required packages:

```bash
pip install -r requirements.txt
```

Run:

```bash
python analysis.py
```

### Power BI

Open:

```
Food_Delivery_Analytics.pbix
```

Refresh the SQL Server connection if required.
